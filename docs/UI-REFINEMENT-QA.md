# SeoulScene UI refinement review

Scope: presentation only. No routes, data records, API/provider behavior, SQLite configuration, schema, synchronization, authentication, or business logic changed in this refinement. No package added.

## Before → after

- Essential labels and controls were commonly 6–11px → shared caption/metadata/control tokens, readable body copy and 16px search/select fields.
- Multiple responsive heading overrides → fluid hero/page/section/poster scales; balanced line wrapping and a 68ch article reading measure.
- Five narrow tablet posters and cropped featured photography → three-column grids and a full-width featured image at 651–900px.
- Three cramped mobile cast columns → two columns with larger names and readable role labels.
- Small mobile header controls and crowded footer columns → 44px icon/link targets and two-column footer groups.
- Dark mobile culture panel retained a pale background → theme-token background with readable foreground text.
- Caption arrows competed with titles → reserved caption space. Detail hero fixed height → content-aware minimum height to accommodate wrapping.
- Large Korean word, original illustrations and photo sources preserved. Footer blossom opacity reduced where it approached small print.
- Three existing families retained and configured with next/font/local. 59 redundant typography/radius declarations removed before formatting; full CJK fallback remains unicode-restricted.

## Files changed in this refinement

- `app/layout.tsx`: local font configuration and CSS variables.
- `public/fonts/fonts.css`: retain only full Korean fallback; remove duplicate font declarations now generated by Next.
- `app/globals.css`: typography/spacing tokens, shared controls, grids, responsive layout and dark-mode corrections.
- `app/editorial.css`: editorial reading scale, heading consistency, actor spotlight and category navigation.
- `docs/DESIGN-SYSTEM.md`: actual font setup, scale and responsive rules.
- `docs/UI-REFINEMENT-QA.md`: this review.

Earlier implementation changes already present in the worktree are outside this file list.

## Verification artifacts

Before screenshots: `/tmp/seoulscene-ui-before/` (home, article and actor pages at all five widths).
After screenshots: `/tmp/seoulscene-ui-after/` (home, discovery, drama detail, article and actor at all five widths in light/dark themes; 50 images).
Browser harness: `/tmp/seoulscene-qa/ui-qa.mjs`; machine-readable results: `/tmp/seoulscene-ui-after/results.json`.

The Chromium suite covers 17 route layouts × 5 widths (375, 390, 768, 1024, 1440) × 2 themes. It checks horizontal overflow, broken loaded images and client exceptions. Axe runs on five representative pages in both themes at 375px. Interaction checks cover Korean search, watchlist, keyboard menu/Escape, visible keyboard focus, input text size, reduced motion and hero reveal. Screenshots are also inspected visually; these checks do not establish that every possible content combination is flawless.

Lucian gallery search confirmed #373 Five underline hovers remains appropriate. Its existing React adaptation, wine/ink tokens, keyboard state and reduced-motion behavior were retained. No new component or animation was needed.

Not covered: Safari, Firefox, physical touch devices, live provider/network services or a new Lighthouse audit. Existing backend tests are not part of this presentation-only review. Screenshot and QA artifacts under `/tmp` are local and may be removed by environment cleanup.
